# Glossary

Fernway's own vocabulary. Use these terms exactly as defined here — "account" and "venue" are never interchangeable.

## Account vs venue

One **account** can have many **venues**. Contracts are per account; billing is per venue. New hires mix these up constantly — if you're not sure which one you mean, say both.

## Pay rules

The per-country break and overtime configuration set during onboarding (Germany, the Netherlands, Ireland). See [onboarding/pay-rules.md](onboarding/pay-rules.md).

## The importer

The CSV staff-import tool used during onboarding. Known to fail on names with non-Latin characters and on files exported from Apple Numbers. See [onboarding/importer.md](onboarding/importer.md).

## T2L

Time to live — contract signed to first schedule published. Fernway's main onboarding metric. See [onboarding/t2l.md](onboarding/t2l.md).

## Ghost shift

A published shift nobody claimed. The single most common support complaint. See [support/ghost-shifts.md](support/ghost-shifts.md).

## Friday freeze

The no-deploys-on-Friday rule. See [engineering/releases.md](engineering/releases.md).

## Mara-check

What the team calls a pricing exception that needs the CEO's sign-off. See [company/pricing.md](company/pricing.md).

## Activation — open decision

Used by everyone, defined by nobody. Three competing definitions are in active use, and this repo does not pick one — see [decisions.md](decisions.md#2-activation).

- **Sales' definition:** first published schedule.
- **Lukas's definition:** a full week scheduled.
- **The Metabase dashboard's definition:** something else again — what exactly it measures is a gap (see [ops/tools.md](ops/tools.md)).

Do not use "activation" in a page without saying which definition you mean.
