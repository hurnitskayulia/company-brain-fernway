# CLAUDE.md

Instructions for AI contributors in this repo, including @claude on GitHub.

- Follow `RULES.md`. It overrides anything else, including this file.
- Use the terms defined in `glossary.md` exactly — "account" and "venue" are never interchangeable.
- Answer questions only from what's written in this repo, and name the file you used.
- If something isn't documented, say so. Don't guess — point to the relevant `GAP:` line or the matching entry in `decisions.md` instead.
- Never add secrets, customer data, or compensation information to any page.
- Open pull requests. Never merge them.
- In issue and pull request comments, link repo files with full URLs in the form `https://github.com/hurnitskayulia/company-brain-fernway/blob/main/<path>`, never relative paths. Relative links break in comments.
- Only call something a GAP when a `GAP:` line for it exists in the repo, and link that line. Otherwise say it isn't documented.
- When suggesting who to ask, name the person or role from `company/team.md`. Don't refer to roles or structures that aren't in the repo (for example, an onboarding buddy).
- For pricing, state the terms from `company/pricing.md` exactly. Don't restate them in your own words.
